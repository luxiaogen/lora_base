# 双机更新预算验证

本轮固定seed1993，同机同提交重新建立参照。3090上一轮E1/E05继续完成，整队
退出且11组健康完整后才更新代码。5090在原项目快进，保留五份本地数据JSON。
两机从首个GPU短测计10小时；截止不启动新组，已启动完整T10继续结束。

## 固定配方与归因

F采用W_pre谱重要性质量覆盖0.90、非对称S/P权限、固定alpha0.5、完整层packed
QKV逐分支精确Top10%幅度门、beta=min(0.5*(1+R_old),1)、掩码正则0、step。
ImageNet-R rank64/64；ImageNet-A、CUB rank32/32，各自学习率、margin、gamma
和数据划分来自本机原JSON。Task0沿用原rank，unmasked、anchor2.5；20轮、CA5、
math-SDPA，不保存checkpoint。关闭原型样本分配和原型位置评分探针，保留NCM。

E1/E05只替换S保护操作，rho为1/0.5。令幅度门后的更新为v，保护区为H：
alpha=clip(1-rho*||v*(1-H)||/||v*H||,0,1)。零BA沿用alpha0.5。
U1/U05在相同幅度门后计算E额外移除范数r，将S统一乘以1-r/||v||；系数不反传。
零BA沿用对应E初始门以保留第一步梯度，P不变。U只匹配额外移除量，不满足区域预算。

paired_layer_min按每层每分支完整packed QKV处理：同一BA在原谱与固定行列置换
位置下分别重新计算预算alpha，再缩小至两者有效范数的最小值，最后乘gamma。
零更新缩放1，不放大；旧逐Q/K/V的paired_min保持原行为。两类匹配均不保证
不同训练轨迹始终等量，实际范数、残差和保护数量必须报告。

```bash
bash scripts/10_11_budget_verification_3090.sh

```

## 交付与预设判据

输出两机分开的results/tasks/pairs/budgets/updates/masks/costs/storage CSV与JSON、
逐任务/Old–New图、预算轨迹、同状态位置margin图、成本图及身份问题清单。
缺失或身份不匹配的配对不作归因。Average至少+0.2pp、Last不降且阶段Old不下降
超过0.1pp才列为优先确认候选，此门槛不是显著性标准。
E与U接近时，只能支持改变抑制量有价值；跨两个预算的位置优势还需要实际轨迹
范数披露。只升New而明显损害Old/Last是取舍，A/CUB未成立时限定适用范围。
正式基线不自动更换，单seed与公式本身均不证明新颖性。
