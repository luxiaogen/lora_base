# 5090：W_pre 互补样本指导（预注册夜间队列）

## 问题与动机

上一轮“教师判对即匹配整条特征方向”没有提点。教师判对不意味着其全部特征都值得模仿；本轮只检验：是否应把辅助约束集中在教师能答对、学生暂时答错的当前训练图片上，而不是限制学生已经学会的图片。

不是 Oracle 推理：训练标签本来可用；教师和学生都在全部已见类别中预测，只用当前训练图片与标签选样。测试标签、真实任务 ID 不参与选样或推理。正常推理不调用教师，仍是原模型一次前向。

## 六组完整训练及执行优先级

| 顺序 | 运行名 | 选样 | 辅助梯度范围 | 回答的问题 |
| --- | --- | --- | --- | --- |
| 1 | complement_s | 教师对、学生错 | 当前 S.B | 优先验证互补选样 |
| 2 | random_s | 教师判对池内随机选，本批数量等于互补数 | 当前 S.B | 排除仅仅减少指导样本数量 |
| 3 | teacher_correct_s | 教师判对全部选 | 当前 S.B | 排除损失归一化改变的影响 |
| 4 | complement_p | 教师对、学生错 | 当前 P.B | 比较指导分支 |
| 5 | random_p | 与 random_s 相同规则 | 当前 P.B | P 分支选样对照 |
| 6 | complement_sp | 教师对、学生错 | 当前 S.B 和 P.B | 联合指导探索；没有 random_sp，不能单独归因选样 |

全部：ImageNet-R T10，seed1993，anchor2.5，Task0/增量训练各20轮，CA5，math-SDPA，原 layer 双门，冻结增量任务 A，辅助权重1。`dual_mask_composed_conflict=off`，不混入另一个在3090运行的组合门候选。

损失统一是 `sum(选中样本的 cosine distance) / batch_size`。上一轮是除以选中数量，因此与旧结果相比同时改变了归一化；第3组是必要的归一化对照。教师为原 AugReg ViT 的 W_pre 特征与固定 alpha=1 的 Ridge 读出；读出只累计各任务当时的训练统计，不回看旧图片。

随机组每一批按**自身训练轨迹**的互补数量选样；模型分化后，两组累计选样量不保证完全一样。必须一起报告实际选样比例及梯度强度，不能声称跨运行严格等剂量。随机选样使用每任务独立 CPU generator，不消耗训练或数据增强的全局随机数。

## 判定与记录

- 完整 T10 的 Average、Last、Old/New、Forgetting 都报告；单 seed 只作为初步结果。
- 互补组优于随机组且相比本机既有基线有净收益、Old 没有明显受损，才支持继续研究。只提高 New、牺牲 Old 或总分下降，不替换基线。
- 若第3组已经获得同样收益，不能归因于互补选样，可能只是约束变弱。
- 既有无教师基线不重跑；引用前核对提交、有效配置、Task0、类别顺序。旧基线与当前代码不是同一提交，必须披露，不作严格因果归因。
- `wpre_teacher_correct_ratio`、`wpre_rescue_ratio`、`wpre_selected_ratio` 逐 epoch 记录；第1/10/20轮首批记录辅助梯度与原分类梯度范数及夹角。
- 不保存 checkpoint，不保存稠密特征或旧图片。保留每组 `run.json`（有效配置、源码 SHA256、提交、命令、退出码、耗时）与完整 `training.log`，队列另存 `queue.json`。

## 运行与时间边界

在原项目、既有 `lys_cil` 环境运行：

```bash
bash scripts/10_02_imgr10_wpre_complement_5090.sh --hours 8
```

先执行专项测试与六组 Task0–1 的一轮 CUDA 短测，全部成功后进入完整训练；短测准确率不是实验结果。完整训练预计约72分钟/组（上一轮独享耗时参照），六组加短测约7–8小时，不承诺固定结束时间。

开始下一组前，按已经完成的最慢一组耗时加10%预留估计；8小时剩余时间不足就记录 `time_budget` 跳过，不按成绩筛掉候选，不强杀正在运行的任务。超出预估时单组仍允许跑完。

可用 `--only complement_p random_p complement_sp` 补跑未启动的组；先从 `queue.json` 确认哪些已完成，避免重复运行。服务器数据及预训练权重路径继续读取本机 `exps/dlora/imgr10.json`，不覆盖本地修改。
