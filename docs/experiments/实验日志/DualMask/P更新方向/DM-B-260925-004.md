# P 更新方向与冲突约束

问题：保持现有双门，在近似相同实际更新量下，通过 P 的 B 方向调整
能否提高 New，同时保留 Old？两台机器分别跑三组完整 T10：baseline、
norm、conflict；每台机器内部配对，不把两台机器当作两个 seed。

共同配置：20 epochs、CA5、math SDPA、P LR0.02、双分支正则0.01、
Task0 anchor10、layer 粒度、当前自适应配置。Task0 未使用新方法。
每5步尝试 P 修正；S 更新保持原 SGD。具体公式、容差和回退规则见
`scripts/README_p_step_direction.md`，扫描范围已固定，不按测试结果扩展。

启动脚本：`scripts/9_25_imgr10_p_direction_3090.sh` 与
`scripts/9_25_imgr10_p_direction_5090.sh`。各读取本机 JSON data_path。
脚本先自动短测，再完整运行三组，最后自动生成 CSV/PNG/PDF。
源代码哈希、Git revision、实际配置在服务器 preflight 和训练日志中记录。

预先判断标准：相对本机 baseline，Average+0.15pp、Last+0.20pp、
阶段平均 New+0.30pp、Old 不低于-0.10pp、遗忘不增加超过0.10pp。
若 norm 与 conflict 相当，只能归因于一般方向预条件，不能宣称冲突定位有效。
当前批次的反事实 loss 不是验证集结果，也不能证明旧类安全。
