# 问题与查重

006修正版配对证明Ridge独立读出强于NCM，额外互补上界仅约0.18pp，不是合法融合收益。
005的NCM置信/交叉支持硬切换没有确认有效；本次不重复这些NCM规则或只打印Oracle。
检验Ridge全类别分数能否通过训练侧保守融合合法取用，实际改变正式预测并得到净收益。

# 协议

两机各完整重训一次DualMask T10、seed1993、anchor2.5、20轮、CA5、math-SDPA。
不单独重训基线：融合前的同批原模型预测构成本次配对基线。
3090外层校准约5%、5090约10%，延续005本机协议；不同留出配置不横比绝对分数。
无旧图片回放，无测试标签/真实任务ID推理，无每任务权重或稠密特征保存。
正融合系数需要两次骨干前向，不能声称保留一次前向效率。

# 候选与数据权限

唯一新增实际预测规则是标准化后的DualMask分数 + coefficient×Ridge分数。
alpha固定1；Ridge Gram/类别和只累计当时当前训练数据，原始W_pre不变，旧数据不重提取。
coefficient只在本任务当前训练留出上按“救回−3×弄错”选择，集合0/0.025/0.05/0.1/0.2预先固定。
Task0固定0，平局和无收益保留基线。策略CA后、正式融合测试前封存。
当前留出没有旧类，不能预设Old不受损；测试报告Old/New与整体净变化，不反过来选权重。
融合预测不受此前两个top1正确并集的严格约束，因为可能选第三个类别；没有使用Oracle选择。
