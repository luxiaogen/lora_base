# 冻结W_pre原型是否能指导S/P的学习责任？

三组同提交重新训练，顺序A→B→C，不复用旧M90成绩作严格配对。

| 组 | 当前训练样本的分类梯度 | 新开关 |
| --- | --- | --- |
| A | 全部样本同时给S/P，原型仅记录 | all |
| B | W_pre原型判对给S，判错给P | prototype |
| C | 每批将B的分配掩码随机打乱，S/P人数不变 | random_matched |

仅Task1–9执行；Task0完全沿用原路径。两支始终参与学生前向，分类头用全部样本。
复用已有类别到达时从训练图片建立的冻结W_pre原型；同一增强图片用于教师和学生，
探针在全部已见类别中预测，使用当前训练标签判断正确与否。不是测试标签Oracle，
不读取旧图片、未来类别，不额外保存样本或历史特征。
正确率是训练分配代理，不当作泛化成绩或真正有益更新的判据。

## 固定配方与实现

ImageNet-R T10、seed1993、20epochs、CA5、math-SDPA、anchor2.5，不保存权重。
W_pre谱重要性质量覆盖0.90（不是90%坐标），S/P rank64/64；非对称权限、保护0.5；
完整每层QKV精确10%幅度选点，选中更新减半，γ为0.5/0.75，step，掩码正则0。
保留现有NCM能力评估、TailUpdate只读记录，不恢复任务级自适应，不添加原型损失。

沿用逐样本CosFace目标，在同一学生前向图上分别计算：

```text
S分类梯度 = grad(mean(分配给S的布尔掩码 × 每样本损失), 当前S.B)
P分类梯度 = grad(mean(分配给P的布尔掩码 × 每样本损失), 当前P.B)
```

分母为完整批次N。普通反传之后只替换当前B的分类梯度，不修改分类头或A梯度、
Attention前向、权限、冲突门及最终合并。保留SGD动量/权重衰减；某批分类梯度为零
不等于该支参数必然不移动。随机分配使用独立CPU generator，按seed及task初始化；
不强行平衡全对/全错批次。探针恢复模型模式及Python/NumPy/Torch随机状态。

## 预先固定的判断边界

- B同时优于A、C才支持原型分工的初步价值，仍披露实际梯度/更新强度差异。
- B与C接近且都优于A，可能只是每支学习量降低，不能归功于原型。
- New提高但Old/Last明显受损，记录为取舍，不采用。
- B不如A则保留M90/rank64，不为补救本轮假设追加阈值、控制器或候选。

GPU短测只证明路由运行，不能算性能结果。正式基线不自动替换；本卡的PID、提交及
状态须在真实启动后补记，不能用本地dry-run打印的PID冒充服务器训练。
