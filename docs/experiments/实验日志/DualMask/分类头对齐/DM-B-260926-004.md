# CA真实新类特征：性能结果待回传

## 目的与唯一变量

检验原CA新类高斯近似是否值得替换，而不是再给骨干增加单向竞争损失。
基线 `ca_real_new_features=false`，候选 `true`。旧类仍使用已有高斯统计；
新类用当前训练数据统计流程提取的真实特征，每类有放回抽样256条。
仅当前任务CPU临时缓存，CA后清理；不新增旧图存储或推理前向。

固定：anchor5、Task0/增量20轮、CA5、math-SDPA、layer双冲突门、P LR0.02、
正则0.01；`old_competition_weight=0`，P方向修正关闭。数据路径读各机器JSON。
原有能量自适应和old-overlap强度适应保留，不能与005固定覆盖率混作单变量对照。

## 设计与实际执行的区别

实际脚本是每机重新训练Gaussian基线、再训练真实特征候选，共2次T10；
不是逐阶段checkpoint分叉。独立采样generator和保留高斯抽样调用，在CPU测试中
保持对应旧类采样与全局RNG，但不能据此承诺完整GPU训练轨迹逐位相同。
CA后分类头本来就可能不同，后续完整轨迹需要单独评估。
