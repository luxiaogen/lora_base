# 原DualMask保护位置与冲突排名的2×2归因

目的为证明原方法哪一部分有效，允许根据证据精简；本轮不承诺提点。
原预训练保护位置×固定置换位置，分别与乘积排名×幅度排名组合，A/B/C/D四组。
用户已同意缺少严格匹配旧记录时只补一次A，另外三组不重跑候选历史扫描。

固定ImageNet-R T10、seed1993、anchor2.5、20epochs、CA5、math-SDPA、原控制器/秩/S/P约束。
Task0不变、增量A随机冻结、B零初始化；不保存checkpoint。
行/列置换在各层QKV独立、固定私有随机数，不改变训练RNG；各投影保护数量和行列占用分布保持。
P塑区为置换后保护区补集；W_pre重要性张量、冲突损失和任务控制保留。
四组统一`dual_mask_conflict_reg_original_score=true`，避免既有幅度模式连正则分数一起改变；
默认旧训练路径不变，本轮只固定正则加权规则，门控改变造成的有效更新变化仍会影响损失。

实现记录真正交付的分支原始/门控后/移除范数与覆盖率；不能用相同覆盖率声称抑制强度相同。
若A/C、B/D都有收益，支持保护策略的位置价值；若伴随抑制量变化，只作策略证据。
B与A接近时乘积排名没有额外优势证据；如仅A有优势则检查交互；如位置无一致效应则撤回精准位置主张。
单seed不是统计显著或等效判断。
