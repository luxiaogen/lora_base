# 权限与信号

Oracle使用真实类别标签，属于离线特权准确率上界；与真任务ID类别范围参照分别报告。
合法信号只读两个全已见类别余弦输出：前两名分差、两候选交叉支持、原模型不确定性。
前两种使用预先固定0阈值；最后一种仅排序。标签不参与规则，不用测试拟合阈值。
当前任务训练数据仅测相同信号，不用于拟合，且不是专家未见过的holdout。
每Task分别记录Old/New的救回、破坏、两者都错、固定规则净收益，以及救回vs破坏AUC。
不拿AUC或Oracle准确率单独当作可部署性能；正式使用双专家可能增加推理前向，必须另算效率。
