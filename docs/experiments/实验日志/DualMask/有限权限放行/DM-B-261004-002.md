# 有限权限放行与任务控制器精简

用户批准双机各约10小时。3090固定7组 A0–A6，5090固定12组 B0–B11，各补一次同提交基线。
按固定顺序，不根据短测/正式测试准确率改变队列；截止后不启动新组，已启动组完整结束。

## 动机与既有证据

上一批 DM-B-261004-001：原非对称权限与均软几乎持平；保护位置优势没有在两种排名都出现。
冲突门有明显旧类保护，额外掩码正则贡献很小。
本轮不再扩大冲突分数/CA扫描，而检验「有限放开有当前任务用途的位置」及「精简线性控制器」两条候选。
保护区内的有益当前更新不等于旧类无害，必须同机完整 Old/New 与匹配对照一起判断。

## 预先固定的判断与交付

1. A1相对A0/A2/A3同时有净收益，才支持分类效用放行；A6用于辨别更新量因素。
2. A0/A4与A1/A5分开判断 P 保护位置；不能等同于整体去掉 W_pre。
3. B0/B6/B7/B8/B9/B10/B11/B1完整后才算2×2×2，未启动/不完整组不补造效应。
4. B1→B2→B3→B4及B4/B5判断控制器、正则、有限放行的交互，不能仅按最好分数选主张。
5. 小单 seed 差异只作候选线索，不自动替换基线。
