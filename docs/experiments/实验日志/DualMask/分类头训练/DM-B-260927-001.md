# 新分类头双向训练：当前新特征＋旧类伪特征

## 问题与动机

旧竞争hinge及detach旧分数已经做过；真实新特征CA见004，均未可靠实现保Old、提高New。
本实验只问：训练时给当前分类头同时提供新类正例和旧类负例，能否减少双向竞争错误？
不是重复真实新特征CA，也不是直接修正P方向；最终Gaussian CA不变。

P LR0.02，mask reg0.01，Gaussian CA，old_competition_weight=0，p_step_direction=off。
不使用固定覆盖率005设置。不修改B0，也不将3090 anchor5历史结果当本轮anchor10参照。

## 方法边界

Task0不启用。Task1起复用已有旧类均值/协方差，按CA均值缩放生成临时256条/类池；
每步从每个旧类抽1条，和本步detach的新特征分别计算全部已见类别CE。
新项先按本batch出现的类别等权平均，旧项每类1条；然后按新/旧类别数占比加权。
额外损失只向新头反传，旧头和特征detach；原损失仍照常训练LoRA。
独立采样流不改变全局RNG；池训练后清理，不新增旧图片访问、持久统计或推理路径。
新头影响后续原损失，不能承诺整个LoRA轨迹相同；历史统计漂移仍是局限。

## 成功与停止规则

先看相对本机参照的Task1–9平均Old/New、双向错误、Average/Last/Forgetting。
只有新→旧减少、旧→新无明显恶化、Old基本保持且总成绩有净收益才考虑保留。
如果只在训练/伪特征指标改善，或收益被最终CA抵消，则不算正式性能获益。
若有效，再另立“仅新特征，无旧负例”的归因对照；不在本轮自动增加候选或权重扫描。
两机不同anchor、同seed，仅各自做配对，不作为多seed统计显著性证据。
