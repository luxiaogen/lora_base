# 原完整 DualMask：四数据集、三 seed 的 3090 基线队列

用户确认用原完整 DualMask，不是精简 M；并追加 CIFAR-100 也开启 CA。
本轮用于建立多数据集、多 seed 的原方法参照，不是新评分或新模块的提点实验。

固定顺序为 CIFAR-100 → ImageNet-A → CUB-200 → ImageNet-R，各数据集依次 seed1993、1996、1997，共12个完整T10。
每个数据集先用seed1993完成Task0–1各一轮GPU短测，四次全部成功才启动完整训练。
短测只验证运行，不参与正式成绩或均值。

Task0 unmasked、训练S的A/B、独立anchor=2.5；增量任务随机冻结A、训练B。20epochs，math-SDPA，无回放、无教师、无方向初始化、无额外CA变体，不保存checkpoint。

## 运行和证据

入口：`bash scripts/10_06_baseline_4datasets_3090.sh`；默认短测后完整队列。
`--mode dry-run`不训练；`--mode smoke`只短测。`--resume 原队列目录`核对配置、源码和完整结果后跳过已完成项。
无时间截止，12组顺序跑到底；运行时不要更新代码或本机JSON。训练异常暂停、不反复重试；纯汇总异常留存，不中断后续训练。
缺失的ImageFolder split不自动创建，CIFAR缺文件不自动下载；开跑前核对四数据集。

输出 `logs/shell_logs/baseline_4datasets_3090/<timestamp>/`：manifest、smoke_queue、queue、active、每组run.json与training.log、results、tasks、aggregate。
run.json记录实际数据集完整配置、源码/配置文件SHA、GPU、软件环境、队列/训练PID。
aggregate只有同数据集三个seed完整有效后才给均值与样本标准差；部分结果不会冒充三seed结论。
