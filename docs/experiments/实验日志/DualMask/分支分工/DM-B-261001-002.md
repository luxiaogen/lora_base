# 动机与查重

已有双门保Old但损失New；统一P学习率、P解冻A、分阶段训练、局部方向投影、
CA修补和旧梯度投影没有可靠净收益。不能从负结果直接推导某个新方案必定提点。
新问题：在真实双门前向中，有限地改变当前S/P B步子是否有更好的选择？
同时记录只有当前训练图片的代理能否识别真实旧训练损失风险。
与DM-B-261001-001不同：不是微小旧梯度投影，而是有限步幅/联合分工选择。
这里“Oracle”为特权信息参照，**不是严格性能上界**；候选仅5个。

# 协议与数据

两机seed1993、anchor2.5、20轮、CA5、math-SDPA，原layer双门与正则，P LR0.02；Task0不改。
数据、设备、预训练路径读取本机imgr10.json，不覆盖。
不保存checkpoint、旧图片、历史稠密特征；临时selector/probe任务结束即释放。
旧数据仅audit/oracle：训练来源、私有generator、selector/probe互斥、不用测试选择。
logit/feature只读当前训练批次，从不构造旧数据loader。
采用候选的SGD动量不修正；这是明确的post-SGD位移过滤。

# 选择与合法信号

保持相同post-SGD分类头，只临时改变当前B；所有候选重新走实际前向与原动态门。
Oracle：旧训练scaled全类别CE不高于原步，从可行集合中选new CE最低且严格改善者。
logit：将同一约束替换为当前新图片的旧头余弦分数变化均方值。
feature：替换为当前新图片归一化CLS变化平方范数均值×0.5。
代理基准是本步前，不是旧模型教师；特征与分数变化不等于遗忘。
P只改变P步长；S/P匹配的是联合B范数，不是有效QKV范数，不能包装成等门控能量比较。
实际CE改善不足1e-7/并列保持原步；old CE容差1e-6，代理容差raw×0.1%+1e-14。

# 预登记判断

1. 生效：非原候选采用数量和步长确有变化；不是只画概念图。
2. 信号：在audit轨迹按任务报告真实old selector CE风险的代理AUC/误报/漏报；
   分开报告Oracle轨迹，不混池、不按测试结果拟合阈值。探针不参与选择。
3. 性能：完整T10报告Average、Last、Old/New、Forgetting和Task0；Oracle不作正式方法结果。
   合法候选若只New提高、Old/总成绩下降，不采纳。单seed小幅差异不能承诺稳定提点。
4. 参照无收益则仅否定此候选集合；参照有收益但合法信号无识别力则不声称逼近上限。

预算按实测耗时估计；剩余不足跳过并记录、可手动续跑。不按测试成绩晋级。
不能保证每个T10候选都在当晚完成，也不强杀训练来凑6/8小时。
