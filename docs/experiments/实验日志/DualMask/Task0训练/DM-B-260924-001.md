# Task0 训练轮数和学习率

## 原始任务与完成情况

固定 seed1993、anchor 权重10、math SDPA。Task0-only 的三组启用确定性训练集 holdout；另外做了一次 Task0 30 轮的完整 T10 复核。Task0-only 解析器显示 1/10，是有意只跑一任务，并非训练失败。

| Task0-only 设置 | Task0 测试准确率 |
| --- | ---: |
| 20 epoch，LR0.02 | 96.52 |
| 30 epoch，LR0.02 | **96.81** |
| 20 epoch，LR0.01 | 96.23 |

Task0-only 的训练集被重新划出 holdout，不能把这些绝对值与完整数据训练直接严格配对。完整 T10 的 Task0 30 轮运行得到 Task0 **96.66**、Average **86.933**、Last **82.35**、Forgetting **5.3556**。该完整运行没有证明增加轮数带来整体净收益。独立 anchor 权重始终为 10；本实验不是 anchor 强度比较。
