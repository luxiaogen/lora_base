# 两种参考权重的相对幅度评分

目的：在精简 M 上检验是否有比绝对更新幅度更有用的排序，不增加教师、损失或任务控制器。
这不是已经有效或已经证明新颖的机制。此前乘积、谱、符号、关系评分不能当作本轮正向证据。

## 预先固定的两组候选

S/P 分别使用原始 BA（权限门之前）的绝对值，除以参考权重对应输出行的 RMS：

\[
s_{ij}=\frac{|(BA)_{ij}|}{\max\bigl(\sqrt{\frac{1}{d}\sum_k (W_{\mathrm{ref}})_{ik}^{2}},\epsilon\bigr)}.
\]

- `wpre_relative`：参考固定预训练 W_pre。
- `task_relative`：参考任务开始时、已合并此前任务更新的 QKV 权重。骨干在任务训练中冻结，尺度整任务固定。
- 每层完整 QKV 精确选取最高 10%，S/P 分别选；不是每行 10%，不是 P 可塑区内 10%。选中位置衰减 0.5。
- 只从 Task1 开启。Task0、独立 anchor2.5、固定权限、rank64/40、CA5、20 epochs、math-SDPA、零掩码正则、其他 M 设置不变。
- 行 RMS 只缓存为每层 2304 个浮点数；不保存历史图片/激活矩阵，不改变正式推理。CA 原有协方差仍存在。
- epsilon=1e-12 仅防止零行除零；不是新的扫描系数。小权重元素不会单独成为分母。

直觉：绝对变化一样大，对原本尺度较小的输出通道可能是更大的相对改动；任务开始权重还包含已学到的适应。
这不等于“相对变化大就是有害”，可能反而压制有用新知识，必须由 Old/New 和总成绩判断。

## 记录与判据

沿用逐任务准确率、Average/Last、最终与阶段平均 Old/New、Forgetting、分阶段成本和持久张量字节数。
每个任务/epoch/层/分支/QKV 记录原始、权限后、最终和移除范数；新增与同状态纯幅度掩码的 Jaccard、参考行 RMS 范围。

固定坐标数和 beta **不保证实际抑制范数相同**。若候选仅通过更多抑制换来 Old，而 New 或总成绩下降，不保留。
若 Average/Last 出现一致净收益且 Old/New 没有明显代价，才进入强度匹配验证；不能单凭这轮宣称更精准定位有害坐标。
若掩码几乎相同且成绩接近，停止该排序方向，不围绕 epsilon 或归一化指数扫参数。单 seed 不宣称显著或等效。
