# 动机与查重

此前独立S/P双门提供Old保护，但New受限；分类头/CA修补和预训练特征教师尚未解决净提升问题。
本轮不是再加特征保持损失：把抑制对象从两个分支各自的更新，改为基础保护/可塑区之后实际合成的净更新。
目标是避免两个独立门破坏S/P已有的抵消关系；不是预先宣称净更新小就对旧类安全。

# 协议和六组

3090原项目、完整ImageNet-R T10、seed1993、anchor2.5、20轮、CA5、math-SDPA。
六组net/gross/magnitude/uniform/w_pre/random；不重复原基线、不保存权重、不跑多seed。
选点K沿用原独立分支自适应预算的平均；仅共享门评分/均匀匹配方式不同。
同权重处匹配K或移除范数，不宣称跨训练轨迹每一步相同。
没有回放、教师、任务ID推理、测试标签参与训练、分类头或CA新改动。
其他互斥机制关闭，配置约束在tests验证，数据路径读取3090本机JSON。

# 预先判定与证伪

报告Average、Last、Old/New、Forgetting、实际密度/抑制量，不用测试结果在队列中自动选方法。
若只是New升Old降，没有总净收益，不替换基线。
若net与gross相当，不能声称收益来自抵消感知；若与uniform相当，不能声称精准选点；
若与magnitude相当，不能声称预训练重要性评分更优。
共享门不放大/反向净更新是数学性质，GPU短测/代码启用只验证实现，均不是性能结论。
本轮不承诺文献新颖性；须等完整结果及文献查重后才能形成论文贡献。
