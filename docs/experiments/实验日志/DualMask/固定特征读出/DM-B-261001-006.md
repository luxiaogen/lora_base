# 问题与查重

两专家合法选择005没有确认净收益；原 NCM 的互补救回少、可能弄错的样本多。
用户批准先检验是否“读出太弱”，而非继续搜索置信阈值。
原网络中的 legacy ridge 依赖当前变化的特征，不作为本轮固定 W_pre 结果复用。
本轮是新的固定原始特征读出对照，不重跑 DualMask、不改变 S/P 或 CA。

# 配对协议

两机各自一遍完整 T10、seed1993、math-SDPA；固定 AugReg ViT-B/16 原始768维特征。
NCM 和 Ridge 共用拟合样本；当前任务添加 G/Q，旧训练图片不再次访问。
Task0内部训练留出选一次 α，之后规则固定；测试仅报告。
复用各机器005的正式缓存及配置，重建各自外层排除。
Task0内部留出仅用于选择 α；系数固定后回填内部留出数据，两个读出最终共用全部允许训练样本。
Task1+直接添加全部允许的当前训练样本。原NCM的内部留出用于能力评估，不用于删掉最终原型样本。
3090约5%/5090约10%的外层排除不同，不作为跨机性能差异的归因。

不保存权重、图片、稠密训练特征；长期统计约2.84MiB。诊断测试特征只在RAM保存且不参与拟合。
缓存缺失/协议不符/索引标签不匹配/NCM复算预测不同：保留独立结果，配对字段为空，不强行补数据或中断训练。
全部模型/读出计算后报告的互补并集依赖真实标签，是上界，不是正式成绩。

两机外层训练排除不同，不横比绝对准确率。上述结果仅支持同一份80%拟合数据中 Ridge 比 NCM 更强，
不证明 Ridge 能救回更多 DualMask 错例，不属于 DualMask 的正式提点结果。

异常：所有任务均 `ncm_reproduction_mismatch`。最终与缓存NCM的预测一致率分别91.483333% / 91.300000%。
`base_average` / `ridge_complement_oracle_average` / `ncm_complement_oracle_average` 均为空。
最后任务中的66.85% / 67.10%是 NCM 与 Ridge 的正确预测并集，不是 DualMask 互补上界。

已确认代码原因：`utils/dual_mask_metrics.py::split_prototype_competence` 用内部留出估计能力后，
返回 `build_prototypes(features, targets)`，建立最终原型时使用全部允许训练样本；
新读出脚本却把内部留出从最终 G/Q 排除了。样本使用规则未对齐，不能强行放行旧缓存。
