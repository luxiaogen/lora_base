# DualMask 组件—证据与候选查重

表中“实现”与“性能贡献”分开；历史单seed结果不承担多seed或跨数据集结论。

| 组件/命题 | 当前证据 | 研究取舍 |
|---|---|---|
| W_pre定义保护位置 | 代码已实现；近期纯幅度实验没有去除它。缺少保持形状分布、容量的保护位置对照 | 本轮A/C、B/D补验，不提前声称位置精准 |
| S/P非对称分工 | S软保护、P补集限制已实现；两者并非互斥特征子空间 | 保留；独立贡献须后续同容量同构门控对照，本轮不自动扩展 |
| S/P冲突门 | [历史配对](实验日志/DualMask/研究收敛/DM-B-260926-001.md)在关闭训练期冲突正则时，开启双门Average+0.812pp、最终Old+2.67pp、New−4.66pp | 支持该协议下保护/可塑性取舍，不能归因为精确评分，也不移植为B1提升量 |
| 乘积排名优于幅度 | [40%硬置零](实验日志/DualMask/P更新稀疏/DM-B-261001-003.md)：Conflict87.011、Magnitude87.012；其他评分探索也未形成一致优势 | 降为辅助选择规则；本轮A/B、C/D检查独立作用 |
| 任务能力控制器 | 从当前训练数据的W_pre原型能力调节保护与容量 | 作为配套设计；未把“自适应”本身写成已证实贡献 |
| Task0 anchor2.5 | 3090两次完整T10为87.214、87.281，Task0均97.10；源码、诊断、权重保存设置不同 | 工作配方有T10支持；不是严格同配置均值/方差，B1卡已更新 |
| 白化/权重先验构造A | 八组完整T10均完成，最佳白化Average86.524、Old79.97，未超过历史原配方，且实际更新范数不同 | 归为候选探索，停止将其作为原方法主线或包装成成功替代旧敏感子空间 |
| 教师、分类头、CA修补 | [近期收敛台账](实验日志/DualMask/研究收敛/DM-B-260926-006.md)及各原实验卡 | 保留原始材料，归为候选探索；本轮全部关闭，原CA保留 |
| 单次编码器推理 | 合并后清除临时LoRA、全部已见类别分类已实现 | 报告推理实现/成本；不单独宣称已有独占新颖性 |
| 无历史激活子空间维护 | 原A随机冻结、保护图由W_pre构造；CA协方差与类别原型仍存在 | 只对LoRA基/保护维护声明，不声称整个方法无二阶统计 |
