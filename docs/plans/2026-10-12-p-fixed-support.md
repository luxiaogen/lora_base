# 3090：可塑区内固定 P 更新支持

用户确认预热2轮、保留可塑区50%坐标。ImageNet-R T10、seed1993，四组同提交重新运行，固定顺序 A→B→C→D；10小时后不启动新组，已启动组完整结束。

| 组 | P 在预热后的规则 |
|---|---|
| A | 当前精简 F 参照，动态完整QKV Top10%幅度门 |
| B | 可塑区内按预热结束的绝对 BA 幅度选择固定 Q，后续只保留 Q |
| C | 可塑区内独立随机选同数量 Q，后续只保留 Q |
| D | 固定 B 式参考 Q，但对整个可塑区统一缩小，逐状态匹配参考 Q 额外移除范数 |

公共配方：W_pre 谱重要性质量覆盖0.90，S/P rank64/64、γ0.5/0.75；S保护强度固定0.5，P硬补集；S动态精确Top10%幅度门；β=min[0.5(1+R_old),1]，R_old=max(0,C_new−C_all)；掩码正则0，20轮、CA5、math-SDPA、Task0 unmasked/anchor2.5，不保存checkpoint。保留NCM流程。关闭预算α、原型分配、原型位置、Wt探针等探索。

前三轮时序：第1–2轮三种候选都沿用原P门；第2轮结束构造一次Q；第3–20轮使用新规则。后三组同时取消原P幅度门。K=floor(0.5×每层完整packed QKV内可塑坐标数)，按固定索引处理幅度并列；随机使用独立CPU生成器，种子由seed/task/layer确定。A同样执行只读的支持构造和记录，保证流程成本可见。

D的匹配：u0=(1−H)⊙BA，r=||u0⊙(1−Q)||F，η=r/||u0||F，uD=(1−η)u0；η不反传，零范数时η=0，最后乘γP。这匹配同一状态的额外移除范数，不保证独立训练轨迹完全等量。Q固定，均匀系数可随BA变化。S可能补偿P，因此同时记录两支和合成更新。

实现限定：新增默认关闭p_fixed_support=off|magnitude|random|uniform_matched；warmup_epochs=2、keep_ratio=0.5。只在任务开始清空、轮末捕获、有效更新形成和合并清空处接入。B仍训练，A保持冻结。Q不会在最终BA上重选；任务合并只发生一次，不保存历史Q。配置组合检查只在入口和测试。
