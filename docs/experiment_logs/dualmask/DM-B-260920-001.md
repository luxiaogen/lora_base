# DualMask 阶段性实验结论（2026-09-20）

## 证据边界

- 正式指标：不知道测试任务 ID、一次全类别推理得到的 CNN top-1。
- Oracle：使用真实任务 ID 或真实标签选择干预，只能作为机制诊断上界。
- Task0-2 短程实验：用于筛选机制，不能替代完整 T10 多 seed 结果。
- 单 seed 提升：只作为方向性证据，不称为稳定性能改进。
- 编译、单元测试和 smoke test：只证明执行路径正确，不证明准确率提升。
- 不同机器之间不直接相减；优先比较同机器、同 seed、同配置的配对结果。

## 已支持的核心结论

### 1. 数据目录不是性能差异来源

两份 ImageNet-R 目录在以下项目上均一致：

- 相对路径和文件字节；
- RGB 像素内容；
- train/test 划分；
- 类别映射；
- ImageFolder 枚举顺序。

两份数据都存在相同的内部重复，因此没有证据表明其中一份通过数据差异获得优势。

### 2. CA 不是主要下降来源

CA 整体有小幅正作用，主要改善 New 和部分任务识别；对 Old 的帮助较弱。取消
mean decay、学习 task bias、边界伪特征校准等变体没有形成稳定提升。因此保留 CA5，
停止继续扫描 CA bias、decay 或 task temperature。

### 3. 主要误差之一是跨任务分数不可比

知道真实任务 ID 后，任务内分类准确率明显高于普通全类别推理。这说明模型在正确任务内部仍有
较好的类别区分能力，主要损失之一来自不同任务分类头之间的分数竞争。

但是 Oracle task ID 不是正式 CIL 成绩，不能据此声称已经解决任务混淆。

### 4. P 冲突区是真实的稳定性—可塑性竞争区

完整 T10 的训练/合并配对结果：

| Seed | Baseline Avg | Conflict-50 Avg | Baseline Forgetting | Conflict-50 Forgetting |
|---:|---:|---:|---:|---:|
| 1993 | 87.075 | 87.064 | 5.4089 | 4.6089 |
| 1996 | 86.465 | 86.490 | 7.0411 | 6.3089 |
| 1997 | 86.454 | 86.211 | 6.7167 | 6.1522 |

统一削弱冲突区在三个 seed 上均降低 Forgetting，但 Average 并不稳定，seed1997 明显下降。
因此冲突区同时承载：

```text
对新任务有用的知识
        +
对旧任务造成干扰的更新
```

`M_conflict` 能定位敏感竞争位置，但不能直接等同于“有害更新掩码”。

### 5. 层、Q/K/V 和 LoRA rank 分组仍然太粗

- 临时删除 K/V 冲突贡献通常更容易改善 Old，但也更容易损害 New。
- 删除 Q 的影响相对较小，但没有稳定的分类收益。
- Layer3-K 曾在多个阶段呈现双正 margin，但变化约为 `1e-5` 到 `1e-4`，没有实际
  corrected 样本，不能据此永久删除。
- LoRA rank-group 功能筛选在 selector 上选出候选后，在独立 evaluator 上
  corrected=`0`、broken=`0`，分类准确率不变；margin 变化很小且 New 方向偏负。

结论：位置敏感性已经得到支持，但有害性识别尚未得到支持。

## 已停止或不再优先的方向

| 方向 | 观察 | 决策 |
|---|---|---|
| All-seen/global 分类训练 | 新任务样本对全部旧类竞争的梯度会反传 LoRA，性能大幅下降 | 停止 |
| detached head calibration | 避免 LoRA 梯度后仍无稳定收益 | 停止 |
| task bias / boundary calibration | 常见现象为 New 上升、Old 下降 | 停止 |
| soft task weighting | 不确定样本仍会整体缩小 P，New 明显受损 | 停止 |
| predicted one-hot | 有少量 corrected，但 broken 接近或更多，二次前向耗时增加 | 不进入 main |
| conditional one-hot | 三次 Average 约 `+0.107/+0.199/+0.172pp`，但收益小且增加推理复杂度 | 保留为负结果/候选，不作为主线 |
| Top-2/Top-K counterfactual | 真任务召回不足，候选排序也不可靠 | 停止 |
| NCM / W0 prototype router | 不能稳定区分 corrected 与 broken，且可能损害 New | 停止 |
| QV/QK 微调 | 从头训练后仍不如原 QKV 稳定 | 保留 QKV |
| S/P LoRA 继承 | 没有跨数据集、跨 seed 的稳定提升 | 保留 fresh 初始化 |
| 固定 P rank | 与自适应 P rank 接近 | 自适应 rank 不再作为核心贡献，可在收紧方法时简化 |
| P conflict norm | Task0-2 Average 仅从 92.8767 到 92.9567，同时 New 从 87.29 降至 86.63 | 不补完整 T10 |
| 旧输入子空间 | Task0-2 Average 92.9533；随机子空间反而为 93.0067 | 不能证明旧特征协方差必要，停止 |
| 冲突区统一减量 | 可减忘，但无法稳定提高 Average | 作为减忘消融，不作为性能模块 |
| CL-LoRA 最小插件门控 | 最终 top-1 略有变化，但 Average 未提升且 New 受损 | 固定 gate 不能称为通用插件 |
| SD-LoRA 插件门控 | 完整公平对照受到 OOM/运行不完整影响 | 证据不足，不作迁移成功声明 |

## 关于迁移性的准确表述

当前实验支持：固定的 `W_pre` mask/gate 不能不经适配地作为通用即插即用插件。

当前实验不支持：完整 DualMask 思想在任何其他方法上都无效。CL-LoRA、SD-LoRA 的分支生命周期、
更新参数和合并方式与当前 S/P LoRA 并不完全对应。若针对宿主重新设计，就属于新的混合方法，
需要重新做归因，而不是简单插件验证。

停止条件：如果 `functional_oracle_holdout` 仍没有真实 `corrected > broken`，或不优于等能量
对照且无法保住 New，则永久停止“从 P 冲突区筛选有害方向”这条研究路线。

## 当前方法应如何收紧

建议保留：

```text
W_pre importance
        ↓
M_protect / M_plastic
        ↓
S 分支保护 + P 分支可塑区域学习
        ↓
固定冲突软抑制
        ↓
安全增量永久合并一次
        ↓
CA + 一次全类别推理
```

暂不纳入最终方法：relocation、safe residual、task router、NCM router、task bias、继承式初始化、
旧特征子空间、额外 Norm、推理时动态删除 P 分量，以及继续扩展自适应权重。

## 后续优先级

### Priority 0：完成 SVD 停止实验

只执行当前 seed1993、Task0-2 诊断，不扩充多 seed。根据预先设定的停止条件决定是否终止方向。

### Priority 1：测清 Task0 运行方差

同一台机器、同一 seed1993、固定数据顺序和 CUDA 设置，重复 Task0-only 三次。记录数据枚举、
初始化 LoRA、最终 Task0、合并前后差异。目的不是选择最高 checkpoint，而是确定可检测的最小
性能变化，避免把运行波动当作方法收益。

### Priority 2：统一跨任务分类分数

若继续优化正式性能，优先研究训练、CA、推理一致的 cosine classifier：

```text
feature L2 normalization
classifier weight L2 normalization
all tasks share one fixed logit scale
single-pass global class prediction
```

它不预测任务 ID、不增加 Router、不需要第二次前向，直接针对“不同任务头分数不可比”。第一轮只做
ImageNet-R seed1993、Task0-2 的当前分类头与统一 cosine classifier 配对。只有 Average 至少
提升约 `0.20pp`，并且 Old/New 均安全，才进入完整 T10 多 seed。

## 防止重复实验的执行规则

1. 新想法先写清唯一改变量和停止条件。
2. 优先 Task0-2 seed1993；未达阈值不补完整 T10。
3. Oracle 只用于定位潜力，不直接转成正式方法结论。
4. 小于重复运行波动的提升不继续扫权重。
5. 同一失败机制不通过更换名称重复测试。
6. 服务器脚本只读取机器本地 JSON 的 `data_path`，不硬编码数据路径。
