# 合法逼近两专家互补上界

同一台机器每次只训练一个 ImageNet-R T10 seed1993，然后缓存两个专家的预测和少量标量。
所有规则共用这一份缓存，不为每个阈值重复训练。原项目、原分支，不保存权重。
固定 anchor2.5、20轮、CA5、math-SDPA、原layer双门。仍读取各机器 imgr10.json 的数据和预训练路径。

## 从已完成结果得到的依据

3090 b6233cb 的两专家正确并集 Average88.956659，原模型87.222975；是使用真实标签的输出选择上界，非正式方法成绩。
0阈值分差/交叉支持分别85.852708/85.846168，十个任务均无净收益。
Task9交叉支持AUC0.891078，但救回84、弄错211，不能由高AUC直接推出阈值有效。
原始NCM的整体准确率远低于训练模型，候选以默认base、少量高把握切换为原则。

## 两机分工与数据权限

| 机器 | 先做什么 | 新运行 |
| --- | --- | --- |
| 3090 | 自动复用上一轮完整CSV，32条旧信号规则，CPU初筛 | Task1–9每类每20张留1张，约5%；一轮T10、41条规则 |
| 5090 | 不要求复制3090数据 | Task1–9每类每10张留1张，约10%；一轮T10、41条规则 |

Task0不留出图片，不加新损失、不改anchor或训练，选择器固定使用base。
留出位置在当前训练集各类内部确定性选取，无随机抽样。
留出图片从DataManager的所有train-source请求移除：LoRA训练、W_pre-NCM原型/自适应统计、CA统计均不能使用它们。
到Task1后只读取当前任务的留出图片，不重新读取旧任务图片，不存图片、特征或历史P分量。
训练类标签可用于拟合选择器；测试类标签和真任务ID不能用于拟合、阈值或策略选择。

5%/10%会改变后续训练样本量、原型和自适应统计；**只能与同次运行的原模型输出配对**。
不能将旧87.223或88.957当成本轮固定基线/固定上界，也不能把两机分差直接归因于留出比例。
本轮属于额外两专家推理：每张图片两次骨干前向，不宣称维持原来一次前向效率。

## 究竟评估哪些规则

旧缓存32条，新数据41条，所有名称预先固定，不按测试效果新增/删减：

| 类别 | 旧缓存 | 新缓存 | 做法 |
| --- | ---: | ---: | --- |
| 固定保守阈值 | 8 | 8 | 分差/交叉支持大于0、0.02、0.05、0.10才切换 |
| 联合条件 | 4 | 4 | 交叉支持超过0/0.02，且base前两名分差小于0.02/0.05 |
| 训练分位数 | 8 | 8 | 仅取训练侧分歧分数高于90/95/98/99分位的正优势样本 |
| 代价敏感阈值 | 9 | 15 | 在训练fit部分最大化救回−cost×弄错；cost=1/3/10 |
| 小型联合信号选择器 | 3 | 6 | 固定ridge强度1，拟合预测切换净收益；cost=1/3/10 |

旧信号：交叉支持、前两名分差差值、base不确定度。
新信号：NCM最高原型相似度−base最高余弦分数；base熵−NCM熵。
熵由全已见类余弦分数统一乘固定scale20计算，非跨专家校准概率。
新信号加入阈值和扩展联合选择器；不修改分类头或骨干。
ridge对所有分歧样本拟合：救回目标+1，弄错目标−cost，两者都错目标0，不丢弃两者都错样本。

## 校准、封存与报告

每任务当前校准集确定性分为约2/3 fit、1/3 audit（index%3==2为audit）。
fit拟合阈值/选择器；audit按预先固定的救回−3×弄错目标选择一条规则；无正收益就选择base。
全部拟合参数、选择规则和SHA在打开该任务测试CSV前封存，不按test重新拟合。
`train_selected`是主候选；其规则来自当前audit，不是41条测试分数最高者。
每条预声明规则的test成绩都报告，属于同一缓存上的对照；从中挑测试最优者只能作探索，不能称为验证成功。

校准仅当前新类，小数据多规则有过拟合风险，也**不覆盖旧类分布**。
成功标准是相对同次base：Average/Last有净收益、New改善且Old基本保住；不是只看AUC或救回数。
旧缓存的current_train_seen_probe被两个专家见过，只是探索性筛选；不得标为独立holdout结果。
本轮还没有GPU/准确率结果，不能承诺逼近88.957。

## 运行命令（Fish交互，脚本是Bash）

两台分别运行，不由本地代理操作服务器：

```fish
# 3090：先旧缓存CPU初筛（存在才用），再短测，最后一轮完整T10
lrun scripts/10_01_imgr10_expert_legal_3090.sh ./logs/10_01_imgr10_expert_legal_3090.log

# 5090：短测，再一轮完整T10
lrun scripts/10_01_imgr10_expert_legal_5090.sh ./logs/10_01_imgr10_expert_legal_5090.log
```

短测为Task0–1各1轮、CA1，仅检查路线和文件完整性，不按准确率阻断正式实验。
默认已有3090缓存位置为上一轮日志打印的目录；若不在原位置，指定目录：

```fish
bash scripts/10_01_imgr10_expert_legal_3090.sh --cache-only --cache /实际路径/t10/diagnostics
```

`--cache-only`不启动训练，`--smoke`只短测，`--t10`跳过短测，`--dry-run`只展示命令、不创建输出。
缺缓存时`--run`仍会执行新运行；无缓存的`--cache-only`返回1并说明原因。
上一轮3090全程约88分钟（含短测），新一轮多一点当前holdout前向，估计约1.5–2小时。
5090独享预计同量级，共享耗时以实际资源为准；32/41条CPU评估不等于32/41次训练。

## 输出

`logs/shell_logs/imgr10_expert_legal_<machine>/<timestamp>/`：

```text
reused_seen_cache/                # 仅3090旧缓存探索
smoke|t10/
  run.json                       # 提交、实际配置、源文件SHA
  resolved_sweep.json             # 显式冻结展开的单组T10配方
  training.log
  diagnostics/task_*_*.csv/json   # 样本索引、标签、预测及5个信号，没有稠密特征/logits
  legal_selectors/
    policies/task_XX.json         # 读取test前封存的全部策略及train_selected
    task_metrics.csv             # 每任务每规则Old/New、救回/弄错/切换数、净收益
    summary.csv                  # 全部规则Average/Last/Old/New；不自动挑测试最优

```

解析只读原CSV，不覆盖上一轮数据。输出用新时间戳。
数据缺失检查在脚本中；研究训练路径没有新增assert、math.isfinite或ValueError验证。
